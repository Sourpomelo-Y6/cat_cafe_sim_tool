# 運動教室・読書サロンの通常往復ADV（2026-10-23）

対象：`cat_exercise_class`（猫の運動教室）、`quiet_reading_salon`（静かな読書サロン）。[共通の通常往復](UnityDispatchConversation.md)、[既存途中選択](UnityDispatchEncounterConversation.md)、[Extra](UnityExtraConversation.md)を再利用する。通常往復は5/9か所対応となる。条件・日程・報酬・数値・バランスは変更しない。

## 本文・画面

`CafeDispatchDialogue` の対象と見出し、行き先別本文を追加。出発導入4節→出発／取消→結果3／2節、任意の派遣中説明3節、帰還導入3節→受領／あとで確認→受領結果3節。既存の近所本文と同じ節構成を保つ。本文の正本は `unity_preview_template/Runtime/Standalone/CafeDispatchConversation.cs` の `Lines`。共通節は近所本文の施設名を対象施設へ、話者「お店の人」を「教室の担当者」／「サロンの担当者」へ置換する。

猫名は実際の対象猫の定義から取得。個性を決めつけない既存の短い仕草を共用し、成績・習熟・最大体力向上を約束しない。人物名・施設の来歴・派遣先での具体的出来事を追加しない。既存猫画像とシルエットを使用し、新規画像・音声・実行時LLMはない。

出発の可否・必要特性・疲労上限・解放条件・日数・猫別報酬見込みは既存 `GeneralDispatchView`、帰還時は `DispatchReceivedReward` と既存DTOの確定報酬・帰還状態を表示する。出発費用0、派遣経験1の既存処理を維持する。現設定は両施設とも2閉店・基本報酬300・用品なしだが、本文に固定しない。途中選択の追加分は既存計算で帰還報酬へ反映する。

運動教室の `exercise_program`、読書サロンの `reading_extension` は既存の専用二択ADVで回答する。往復では案内と確定報酬の確認だけを行う。途中回答時の疲労／ストレスと帰還時の報酬受領を混同しない。

共通ADVの最大3行ページ送り・文字速度・即時表示・全文表示／次へ・バックログ・オプション・保存／読込をそのまま使用。任意説明は閉じれば営業・休業で日程を進められる。未確定相談を閉じた場合も新しい制限を残さない。確定後の未読結果は既存の停止理由に従い、イベント一覧の「一般派遣・帰還」から再開し「会話を終える」まで読む。帰還未受領・途中選択未回答は既存の制限を維持する。自動進行は手動で再開する。

## 保存・互換・Extra

行き先を持つ既存 `CafeDispatchConversation`、`LocalCafeDispatchConversation`、`DispatchConversationPanel` を再利用し、保存形式を変更しない。相談キーは `dispatch-{日}-{猫ID}:{行き先ID}`、実派遣は `dispatch-{日}-{猫ID}`。取消後の再相談・他施設への相談・同じ猫の後日の再派遣・複数猫を区別する。確定後は実派遣へ同期し、表示やロードで出発・受領を再発行しない。既存request_id／revision、送信中無効化・同フレーム入力抑止と既存処理の重複拒否を維持する。

会話メタデータのない旧派遣中・帰還待ちはその段階から開始し、過去の出発を既読として補わない。旧受領済みは既存の記録表示へ戻り、会話の既読を補わない。近所の行き先省略・既存の全会話IDと解放済みExtra記録を維持する。

| 会話ID（施設ごと） | 解放する読了分岐 |
| --- | --- |

| 同じ施設IDの `.travelling` | `travelling` |
| 同じ施設IDの `.return` | `received` |

各施設4分岐、計8分岐を既存Extraカタログへ追加。導入のみ・未読・未記録は解放しない。既存の `dispatch.exercise_program.v1`／`dispatch.reading_extension.v1` の `accept`／`decline` は変更しない。回想は保存された本文を共通UIで再生し、派遣・報酬・経験・日付・営業セーブを変更しない。
