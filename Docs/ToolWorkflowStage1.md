## 現在の操作

1. 上部の「制作対象を検索」で猫・人物の名前またはIDを絞り、対象を選ぶ。検索だけでは対象は変わらない。猫画像欄から選んだ猫も資料に対応があれば制作対象へ同期する。
2. 「対象管理」から同じ対象の資料を開く。「文章」の通常／特別入口から同じ対象を編集する。既存の編集窓への移動時は未保存確認を行う。同じ対象・場面を開き直す場合は現在の操作条件を保持する。
3. 広い編集画面では資料・採用本文・登録画像を右側で比較。猫専用セリフも適用猫の画像を使う。共通セリフは画像付きプレビューで比較猫を選ぶ。画像の代替表示・未登録理由を明示する。
4. 狭い画面では「資料・採用文を比較…」で画像を含む別窓を開く。比較窓は開いた時点の表示。再度開くと現在の内容を表示する。
5. 下書き保存→登録内容を確認→確認した文章を登録。人物選択中は猫画像・生成設定を無効化し、紹介文は猫用であることを案内する。人物画像の既存操作は対象管理から利用できる。

状態は未制作・下書きあり・採用済み・未保存、採用文との差分を表示。Unity収録状態はこの画面では検証しない。紹介文は下書きの読み込み元と、登録後も旧下書きを優先する仕様を案内する。

第1段階は既存タブ・子窓を利用した構成。左の固定対象一覧ではなく上部の検索付き一覧を採用した。画像未登録の対象も資料と本文を制作できる。人物画像の配置変更、書き出し入口の集約、4タブ全体の再配置は第2・3段階として残る。
