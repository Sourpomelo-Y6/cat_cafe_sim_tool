## 制作の範囲

不足する実行4枚を組み込み `image_gen` で1枚ずつ制作。各回に行動別baseと `CatAppearance-v1/mike-normal.png` の2枚を参照した。ねこじゃらし・声かけ・見守りは既存実行候補を再利用し、再生成しない。特別な反応は制作しない。画像とこの制作記録のみ追加し、元の画像・登録対応表・ゲーム処理・Unityプロジェクトには変更を加えない。ビルド・コミットは実施しない。

生成画像はプロジェクトへコピーし、生成ツール側の原本も保持する。出力は加工・リサイズせず保存。採用はユーザー確認待ち、ゲーム登録・実画面確認は未実施。

## 用途と確認

| 行動 | 追加ファイル | 準備との違い・目視確認 |
| --- | --- | --- |
| ブラッシング | `mike-brush-execute.png` | 木製ブラシの毛先が右画面側の肩に接する。接触境界と毛の重なりが見え、浮いていない。手の握りと短い爪、手首のつながりに目立つ破綻なし。元と同じ正面座り・巻いた尾・開いた穏やかな目。 |
| ボール | `mike-ball-execute.png` | 片前足が球の上側に接し、足を下ろして見る準備画像から遊びへ進んでいる。球はマット上、反対の前足と後足で支持し、同じ緑とクリームの球・立ち姿・右に伸びる尾を維持。静止画のため転がる速度までは表現しない。 |
| ぬいぐるみ | `mike-plush-execute.png` | 片前足を鼠の背に重ね、灰色の布製おもちゃへ接触して遊ぶ。反対の前足はマットで支持、後足2本と尾も自然。顔を少し下げた視線で、元の座って眺める準備と区別できる。鼠の耳・鼻・布の尾、背景・マットの配置を維持。 |
| トンネル | `mike-tunnel-execute.png` | 後半身がトンネル内に隠れ、前半身と前足が入口の外へ出る通過中の姿。入口の縁が胴体の奥を覆い、単に脇に立つ準備と区別できる。前足2本が自然に接地し、猫の胴体の重複なし。尾と後足は内側に隠れ、見えない部分の形状は確認できない。同じセージ色の筒・壁・床・マットを維持。 |

共通の確認基準は、猫自身の右顔・耳が橙、左が黒、白い額・口元・胸・足、琥珀の目、小柄で丸みのある短毛、暖かな手描きの画風。背景のクリーム壁・木の巾木と床・セージ色のマット、視点と余白を維持する。新しい姿勢や遮蔽による模様・毛筋の細部の差はあり、ピクセル一致を保証するものではない。

ねこじゃらしの既存 `mike-play.png` は羽根へ前足を伸ばす通常の遊びとして再利用できる。元の準備画像とは棒の色や尾の位置に差がある。声かけは `mike-voice-base.png` の話者へ向いた耳・顔・視線で表現できる。見守りは `mike-presence-base.png` の落ち着いた伏せで十分。後者2つの準備を正面座りの基準画像にするのは今回の運用提案であり、既存のbase登録を変更したものではない。

## 後日の登録候補（記録のみ）

猫IDはゲーム用 `cat-mike` と制作・表示用 `playtest-mike` を明示的に対応させる。各行動の準備候補を `<mode>__switch`、実行候補を `<mode>__direct` と `<mode>__adapt` に割り当てる案。`mode` は `teaser / ball / plush / tunnel / brush / voice / presence`。通常と穏やかな実行に共用できるが、強い行動・フェイント・停止・拒否・回避や特別発動の結果へ無条件に流用しない。

登録時は `cat_cafe_sim_tool/interaction_scenes.py` の既存キーと `content_images.py` の登録処理、`cat_cafe_sim/saves/content_images/manifest.json`、Unityのコンテンツbundleと `interaction_texts.json` の `image_bindings` を確認する。Unityの `PythonPlayerPanel.cs` は保存済み `narrative_image` を優先するので、画像キーだけの登録では表示が変わらない場合がある。詳しい選択経路は前回の `../MikePetExecution-v1/Generation.md` を参照。今回は登録スクリプトを実行していない。
