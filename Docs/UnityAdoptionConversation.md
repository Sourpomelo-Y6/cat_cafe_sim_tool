# 猫の譲渡申し出：共通ADV接続

実装日：2026-10-21。対象は既存の申し出の導入→譲渡する／見送る→結果会話。発生条件、初期OFF、営業準備中のON/OFF、閾値、費用・報酬、関係値、在籍数の計算は変更していない。新規画像・音声・実行時LLMは使用しない。

## 本文と確定情報

本文の正本は `unity_preview_template/Runtime/Standalone/CafeAdoptionDialogue.cs`。猫名は申し出のcat_id、お客さんの名前はcustomer_id、日付と親しみ・プレイヤー好感度は申し出時に確定した値を使う。家庭環境・来歴・譲渡後の生活や猫の意思を新たな確定事項として書かない。

導入（{猫}・{客}・数値は対象申し出から置換）：

1. 地の文：「{日}日目、{客}から、{猫}を迎えたいという申し出が届いた。」
2. {客}：「{猫}を迎えることについて、相談させてください。」
3. 地の文：「申し出時の記録では、お客さんへの親しみは{値}、プレイヤー好感度は{値}。接客で築いた関係に沿った申し出だ。」
4. あなた：「送り出すことも、この店で一緒に過ごすことも、大切に考えます。変更されることを確認してから決めましょう。」

譲渡する結果：

1. あなた：「{猫}の譲渡を確定しました。これまで店で一緒に過ごした時間も、大切な記録です。」
2. 地の文：「{客}への譲渡が成立した。{猫}は接客・派遣・個別交流の対象から外れる。金銭報酬はなく、猫の詳細と関係の記録は残る。」
3. あなた：「送り出すと決めたことを、大切に受け止めます。{猫}との記録は、これからもここで見返せます。」

見送り結果：

1. あなた：「今回は譲渡を見送ります。{猫}とは、引き続きこの店で過ごすことにします。」
2. 地の文：「{客}からの今回の申し出は見送りとして記録された。譲渡は行わず、{猫}の在籍と関係の記録を保つ。」
3. あなた：「店で一緒に過ごす選択も、大切にしたいと思います。また申し出があったときは、そのときに考えましょう。」

選択前に「ゲーム内では復帰できません。接客・派遣・個別交流の対象から外れます。金銭報酬はありません。猫の詳細・関係の記録は保持します。」を表示。見送りは費用・報酬なし、店での活動を継続し、翌日以降は既存条件で再提示されうることを表示する。

## 操作と状態

`AdoptionConversationPanel`は既存`AcquisitionConversationPanel`を継承。最大3行の実フォント・幅によるページ送り、文字速度・即時表示、全文表示／次へ、バックログ、保存／読込、共通設定を再利用する。既存画像は申し出の猫IDからContentIdへ変換し、在籍中猫の配列位置に依存せず取得する。画像がない場合は既存シルエット。

「譲渡する」は既存の最終確認へ進む。取消は会話位置、回答、営業スナップショットに触らず選択画面へ戻る。確定時は確認IDを先に消し、既存`resolve_adoption`のみを送信する。共通UIの同フレーム入力抑制、クライアントの送信中抑制、バックエンドのinstance/revision・回答待ち検査で多重確定を防ぐ。譲渡の効果を会話や回想内に実装しない。

回答前／結果途中とも閉じられる。イベント一覧の「譲渡の申し出」から再開する。未回答は従来の営業停止を維持し、回答後の未読結果も営業・休業・おまかせ再開を止める。既存の営業準備・休業不可理由に未回答／未読の理由と再開先を表示する。読了後は他の成長・目標・エンディング等の待ち状態を維持し、勝手に営業を再開しない。

## 保存・互換・Extra

営業セーブ包絡v1の任意項目`adoption_conversations`と`adoption_conversation_selected`を追加。ゲームスナップショット、ルールID・バランスは変更しない。会話IDは`adoption.offer.v1`、分岐は`introduction`／`accept`／`decline`。会話の一覧キーには既存申し出ID（`adoption-{日}-{猫ID}`）を使う。既存仕様が1匹1日1回であるため、翌日の同じ猫は別ID。猫・客・日付の確定情報は対応する申し出を参照し、複数猫・客の回答と本文を混ぜない。

保存前に実回答と結果分岐を同期する。読み込み前に重複・存在する申し出・実回答・分岐・節・完了・既読集合を検査し、不正な保存で稼働中状態を置き換えない。

- 旧セーブの未回答：新たに導入から閲覧できる。
- 旧セーブの譲渡済み／見送り済み：元の回答・猫の状態・記録を保持する。未観測の導入・結果・既読や進行停止を補わない。既存の譲渡履歴画面で回答を確認する。
- 結果会話途中：同じ申し出の節とページ位置を保存・復元。読了するまでExtraを解放しない。
- 閲覧完了：「会話を終える」で当該分岐を既読としてExtraへ結合。

Extraの解放単位は既存共通方式に合わせ、**シナリオ版＋結果分岐**の2枠。同じ猫の翌日再提示や他の客・猫で同じ分岐を読了しても、Extra枠は増やさず、最初に読了した名前・画像ID・話者付き本文を代表として保持する。営業セーブの会話位置は申し出ごとに独立して残す。回想は保存された本文を共通の読取専用ビューで表示し、譲渡コマンド・好感度・飼育枠・営業保存を変更しない。
