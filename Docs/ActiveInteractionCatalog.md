# Editor Playで登録済み3案を有効にする

2026-10-16。Unity EditorのPlayで何度交流しても同じ反応文になるという報告を確認した。

## 原因と対応

通常の素材参照先 `Assets/Resources/CatCafeContent/catalog.json` が、交流文カタログを含まない旧パック `f11cad7b3f174d86a8ca4b102e9dc480` を参照していた。前回の取り込み検証は終了後に元へ戻す方式で、登録済みの3案は通常起動に有効化されていなかった。そのため、固定の試作文が使用されていた。

前回書き出したパックと現在の登録済み文章が同一であることを照合し、既存の通常取り込み処理で `75f31c320b3f4de7978ac2c77f7eada1` を有効にした。参照先には `bundleResource` と `interactionResource` の両方を設定した。今回は検証終了後もこの参照先を維持する。

候補の選択ロジック、登録文章、既存のゲームセーブは変更していない。素材に適用されるのは登録済み52条件・156案で、未登録の条件は既存の試作文を使用する。

## 確認結果

通常のResources読込を使う `LocalCafeBackend` で、ミケへの休憩を4回実行。同じ通常反応の条件から、人物・猫とも案1→案2→案3→案1が選ばれた。

| 行動 | ミケの反応文 | 候補 |
| --- | --- | --- |
| 1回目 | ミケは動きを止めて、静かにその場に佇んだ。 | 案1 |
| 2回目 | ミケは動きを止めて、穏やかな様子で待機した。 | 案2 |
| 3回目 | ミケは動きを止めて、落ち着いた様子でその場にいた。 | 案3 |
| 4回目 | ミケは動きを止めて、静かにその場に佇んだ。 | 案1 |
| 保存・ロード後の次の行動 | ミケは動きを止めて、穏やかな様子で待機した。 | 案2 |

通常の保存・ロード窓口を使い、再開時に過去の完成文章が同一であること、次の候補選択が続きから行われることを確認した。20回の同一閲覧で文章とゲーム状態が変化しないことも確認。既存Canvasの個別交流・席の詳細・履歴・空席も描画した。Unity Editor検証の終了コードは0。

EditorのPlayを一度停止して再開すると、新たな行動から有効なカタログを利用する。反応や操作が変わると別条件の候補を使うので、すべての行動を通じて一律に案1・2・3の順になるわけではない。既に保存された過去の文章を、新しいカタログで作り直すこともしない。

検証入口は `CatalogVerification.ActivateAndVerifyAuthoredPack`。入力パックを `CATCAFE_IMPORT_PACK`、検証先を `CATCAFE_NARRATIVE_OUTPUT` に指定する。成功時は有効化を維持し、検証で失敗した場合だけ元の参照先へ戻す。今回の記録は `Logs/ActiveInteractionCatalog`。以前の `VerifyAuthoredPack` は、引き続き参照先を戻す一時検証として利用できる。

## 容量と保存状態

既存Unityプロジェクトに通常起動用のパックを1組追加したため、取り込み素材は1,680,986,347バイト→2,065,128,120バイト（+384,141,773バイト、約384 MB）。既存のパックは削除していない。新たな書き出しパックやUnityプロジェクトのコピーは作成せず、前回のパックを再利用した。

ツールの生成フォルダは開始・終了とも6,058ファイル・2,820,683,986バイト。Editorの問題のため配布Playerは再ビルドせず、Latestは156ファイル・4,184,220,754バイトの1組のまま、Pendingなし。検証用セーブは専用ログ内に保存し、通常のプレイ用セーブに触れていない。検証に使ったEditorは2021.3.45f1で、プロジェクトの版指定は元の2021.3.45f2へ戻した。
