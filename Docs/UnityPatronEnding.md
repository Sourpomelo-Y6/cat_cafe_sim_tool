# 有力者目標の成功エンディング

2026-10-20実装。派遣条件・満足度・報酬・目標条件・バランスは変更しない。

## 仕様と共通機能

`CafePatronEnding` は固定 `CafeClearRecord(mode=patron)` だけから達成日、目標／達成時の合計満足度、在籍猫数、資金、累計接客売上を表示する。継続後の現在値で再計算しない。個別派遣先・人物との出来事や私的関係は語らない。特定の猫の現所在も推測せず、既存の店内背景・シルエットを使う。新画像生成・音声・実行時LLM・失敗演出は対象外。

人気・好感度の `CafeEndingProgress`、`PopularityEndingPanel`、`AcquisitionConversationPanel`、保存ブラウザ、オプション、バックログ、全文表示、次へ、最大3行ページ送りを共用する。閉じた場合は目標結果画面の「エンディングを再開」から同じ位置へ戻る。読了後は固定成果と「保存」「継続営業」「タイトルへ」。保存は既存ブラウザ、継続は既存 `continue_patron`。営業やおまかせは勝手に再開しない。演出は帰還受取・目標判定・報酬を実行しない。

未読の継続はUIとバックエンド双方で拒否する。既存request ID／revisionの検証と帰還の一度だけの受取処理を再利用する。他目標の結果確認は当該目標の未読だけで制限する。`step_autoplay` の終了処理は未読制限から除外し、成長候補の確定も妨げない。

成長候補、優先required_action、別会話表示中は自動表示しない。好感度・有力者が同時に未確認だった場合、従来はrequired_actionが好感度なのにgoal_resultが有力者となる不一致があった。goal_resultを既存の好感度優先に揃え、好感度→有力者→人気の各結果へ進める。派遣帰還・未回答イベントの優先順や条件は変更しない。

## 本文

本文の正本は `Runtime/Standalone/CafePatronEnding.cs`。以下の「／」は改行。

1. 地の文：あなたはカフェで、有力者への派遣を重ねてきた記録を開きました。／店の外へとつながった活動が、ひとつの成果になっています。
2. あなた：有力者の目標を、最後まで達成できたんだね。／派遣を通じて積み重ねた信頼が、ここまでつながったんだ。
3. 地の文：記録に残るのは、目標を達成した日の成果。／あなたはその数字を、ゆっくりと確かめます。
4. あなた：カフェの中で育ててきた力が、外での活動にもつながった。／これからも猫たちの様子を見て、無理のない歩みを大切にしよう。
5. 営業の記録：固定記録の達成日、目標／達成時合計満足度、達成時の在籍猫・所持金・累計接客売上。／これは目標達成時に記録した成果です。
6. あなた：信頼を育てることも、店の活動を広げることも、一度きりでは終わらない。／この区切りを、これからの営業につなげていこう。
7. 地の文：派遣を通じて育った信頼と、広がったカフェの活動。／その積み重ねを大切にしながら、あなたはこれからの日々へ目を向けました。

## 保存・互換方針

形式1の任意項目 `patron_ending` を追加。ID `ending.patron.v1`、分岐 `cleared`、node、page_offset、completed、viewed_branchesを共通検証する。猫IDは空として特定個体を表示しない。Unityが欠落参照型を空オブジェクトへ変換する場合は他演出同様に未設定へ正規化する。ゲーム状態の形式・ダイジェストや判定係数は変えない。

| 保存状態 | 方針 |
| --- | --- |
| 達成していない／固定記録がない | 成功演出を作らない。成果を現在値で補わない |
| 固定達成記録あり・結果未確認、演出情報なし | 未読として先頭から提供 |
| 既に継続済み、演出情報なし | 営業を止め直さず、閲覧完了もExtra解放も補わない |
| 演出途中 | nodeとpage_offsetを復元 |
| 読了済み | 成果画面を復元。実在する読了情報のみExtraへ取り込む |

読了時だけ独立した `extra-v1.json` へ登録し、エンディング一覧を3本にする。新規ゲーム・旧スロット読込でも解放を保持し、同じ安定IDは重複登録しない。既存 `ReplayConversationPanel` は記録した本文・固定成果を読み取り専用で再生し、営業セーブを読み込まず、コマンド・報酬・継続を実行しない。
