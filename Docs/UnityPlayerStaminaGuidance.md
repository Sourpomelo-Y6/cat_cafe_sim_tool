# 交流後の体力と出勤・休養の案内（2026-10-24）

交流中と結果画面に、対象猫の最新の現在体力／最大体力と出勤・休養予定を表示する。交流履歴の体力とは分け、交流後の体力が営業に引き継がれること、疲労・ストレスは別の値であることを説明する。

出勤予定で体力0なら接客継続不可、既存の `Rules.exchange.low_stamina` 以下ならけだるい反応の注意を出す。最大体力に対する割合の新基準や能力低下は追加しない。表示は `CafeSimulation.PlayerStaminaGuidance` に集約し、ゲーム状態を変更しない。

結果の「営業準備・出勤／休養の設定へ」で対象猫を選択済みの営業準備へ1操作で戻る。次の「休養」は既存の `SetCatShift` を使い、他の猫の予定を維持する。休養案の一括作成・確定は実行しない。予測は営業準備が受信した最新の `shift_forecast` を表示する既存経路を使用し、画面側に計算式を追加していない。

交流中は終了後に変更可能と表示。営業中・閉店後は翌日の営業準備、イベント／目標確認待ちは先に必要な確認、おまかせ中は停止後と案内する。通信中は既存の送信待ち表示とボタン無効化を利用する。営業準備を開くだけでは予定を変更しない。

「休養予定への変更では今の体力は回復しない」「体力は翌日の準備で最大まで回復」「疲労・ストレスの休養回復は閉店時」と区別する。体力・回復量・交流回数・出勤条件・バランスは変更していない。
