# 全猫一覧

2026-10-16時点。ゲームの固定定義は全31枠。作業用アプリの交流文台帳には8匹を登録済み。登録済みは文章完成を意味しない。

同名でもIDが異なる猫は別の定義として扱う。ナナ・ソラ・ムギ・レオなどを名前だけで統合しない。

出典：[ゲーム定義](../unity_preview_template/Resources/CatCafeStandalone/rules.json)、[表示資料](../unity_preview_template/Resources/CatCafeStandalone/presentation.json)。台帳は `../../cat_cafe_sim/saves/content_images/interaction_subjects.json`。

派遣紹介の `intro-…` は表示資料の識別子。元の候補定義では猫IDが空欄なので、交流文のゲームIDへ対応させる際は実際に加入した猫のIDを確認する。子猫など実行時に生まれる個体は固定の全名簿に含めず、加入後に個体IDで管理する。

## 今後の制作

未登録の23枠は、詳細な外見資料・画像素材・実行時IDとの対応を確認してから台帳へ追加する。毛色と毛の長さはゲーム設定にあるが、目の色や顔の模様などは未設定なので推測で確定しない。

台帳の登録済み8匹はミケ・タマ・ソラ・コハク・ムギ・ナナ（引き取り依頼）・マロン・ココ。既存の本文や登録状態はこの一覧作成では変更していない。
