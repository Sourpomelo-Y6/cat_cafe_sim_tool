# 交流行動・反応の累計記録

2026-10-30：推奨案の採用指示を受けて実装。ToolのUnityテンプレートと既存Unityプロジェクトへ同じソースを反映済み。Standaloneビルドは行っておらず、固定Latestの実行ファイルには未反映。

## 使い方と集計単位

猫詳細、またはお客さんの名簿の上部にある「交流の累計記録」から開く。共通画面で猫・人物・接客／プレイヤー交流を選択する。人物にはプレイヤーも含み、猫と人物の両方を選ぶと組み合わせ別になる。譲渡後を含む保存上の猫も選択対象。記録閲覧はゲーム数値や操作回数を変更しない。右側の猫説明文の常設表示は復元していない。

- 主表示は通常交流行動（direct/adapt/intense/feint）の手数。動作種modeと操作actionを別々に保持する。
- pause・switchは補助操作。切替先へ移る操作を、その動作を行った回数には含めない。
- connectは人物→猫の特別な働きかけ、open_upは猫→人物の特別成立。通常反応と併存した事実を保持する。同時成立はそれぞれの内数で、特別成立した手数は1手。
- 確定した拒否反応turn_awayは1手。無効な入力・開始不可・手動終了・待機・休養シフト・未消化pendingでは加算しない。
- 猫では受けた行動と示した反応、人物では行った行動と受けた猫の反応として表示する。人物自身の独立した感情反応は現実装にないため、回数を生成しない。
- 1つの疎集計から猫・人物・ペア・全体を表示し、双方の小計を合算しない。詳細は30項目ずつ、相手別の概要は上位20件。

## 保存・旧保存・失敗時

`CafeSaveEnvelope.interaction_statistics` に専用schema_version、開始day/tick、完全記録か記録開始以降か、IDベースの集計行、進行中交流の処理済みturnを保存する。表示名・文章・画像はキーにしない。同じ組み合わせの反復は64bit件数だけが増える。終了した交流のカーソルは破棄し、全期間のイベントID集合は増やさない。

`StepExchange`は加算を行わない。実営業／実プレイヤー操作から生成した結果をコマンド成功後に一括適用する。おまかせの先読み、表示用の再計算、可否判定、保存検証、リプレイ検証は対象外。同一の処理済みturnの再通知は加算せず、飛び番・相手違いを拒否する。途中保存では件数と進行位置を同じ保存へ保持する。

Backendでは交流を実行し得るコマンドのゲーム状態を事前退避し、例外時には状態と観測済み文章・日次記録を戻して未確定バッチを破棄する。おまかせ内で例外が捕捉された場合も、内側の実操作の未確定行動を残さない。既存の文章通知ExchangeObservedを上書きせず、別の確定通知を使う。

旧セーブの項目欠落／nullは「記録開始以降」へ移行し、読込時点の既消化turnを開始境界にする。過去の回数は補完しない。不正な形式・負数・重複キー・再開位置の不一致は読込を拒否し、黙って0へ戻さない。保存読み戻し時にも検証する。古い保存を読み込むと累計もその時点へ戻る。別スロット・周回をまたぐ合算はしない。旧Python保存の取り込みも同じ開始境界を使う。

追加欄はSnapshot外のためゲーム状態リプレイのダイジェストを変更しない。既存の日次実績・成長・文章履歴は継続し、それらから過去の反応を推定しない。旧アプリで再保存して追加欄が失われた場合は、新たな記録開始以降として扱う。
