# 有力者目標と成長の案内（2026-10-24）

## 変更

目標の詳細・有力者派遣・成長確認へ案内を集約した。希望と一致／不一致時の満足度加点は保存済みの現在設定（patron.members.conditions / gain / unmatched_gain、地域のwelcome）から表示する。厳格な有力者の「白猫 かつ 接客専門」を本文へ固定せず、共通の条件整形を使用する。

派遣可否は既存DispatchReason、満足度は既存PatronGainを利用する。気分変化の現在希望は既存PatronTermsで表示し、派遣済みは保存されたpatron_match・加点を表示する。帰還案件の再判定は追加していない。

成長確認は選択中の全件一覧・猫適性の比較理由・関連する未達条件を表示する。既存の右側候補で手動に切り替え、前／次で各猫を確認できる。まとめて確定と保存前の仮選択の動作は維持する。外見条件を満たす猫だけに専門の案内を出し、未開始／達成済み／その有力者の必要点達成後は個別案内を出さない。専門確定後は変更不可と表示し、振り直しや新しい候補の入手を保証する案内は追加しない。

おまかせ設定にも、猫適性の自動確定は目標達成を保証しないことと、手動育成には中止後の通常営業を使うことを追記した。自動決定の重み・条件・費用・加点・成長処理・セーブ形式を変更していない。新しい必須会話や進行停止はない。

## 検証

検証入口は `PatronGuidanceVerification.VerifyAndBuild`。固定ビルドスクリプトの `-ExecuteMethod` で実行する。白猫／他の外見と未専門／接客／休養の案内、目標未開始／挑戦中／達成済み、表示反復時の状態JSON・推薦理由不変を確認する。既存GrowthBatch・GrowthSmokeで一括確定・取消・手動保持・自動選択・旧セーブ・保存再開・おまかせを回帰確認する。有力者往復の既存回帰で3人×一致／不一致、現在希望と出発時固定、旧セーブ・保存復元・重複防止を確認する。

初回はUnityライセンスIPCの接続タイムアウト（exit 199）。制限外で再実行し起動できた。検証フィクスチャの成長経験値不足を修正後、案内と成長の1,513項目が成功した。数値の長期評価は再実行していない。

最終Editorは1,882項目成功（有力者往復・旧セーブ復元を含む）。.NETの共通C#プロジェクトも警告0・エラー0でコンパイルした。配布Playerは専用保存先を使い、1280×800・1024×768で成長の選択中内容／条件／手動導線と、長文のスクロールを画像で確認した。目標・派遣の撮影結果はResultsに記録する。操作はテストランナーによる既存UI・コマンドの呼出しで、Windows物理クリックの手動検証とは区別する。

初回の画面では条件が一覧の下に埋もれたため、選択中内容・手動導線・関連する条件を先頭へ移した。撮影器の同一フレームでの画像要求上書き、準備画面を閉店中に開こうとする操作、目標タブ未選択も修正してから撮り直した。
