# 主要イベント会話の既読スキップ

2026-10-24。本文・ルール・費用・報酬を変更せず、共通ADVへ明示操作の「既読部分をスキップ」を追加。

## 判定と停止

会話ID（既存の版を含む）・分岐ID・節番号・分岐全体の話者と本文を長さ付きで連結し、SHA-256で識別する。本文の一文字、名前・数値、別分岐の違いも別記録になる。現在のページが全文表示された後の「次へ」で、そのページの文字範囲だけを記録する。「全文表示」だけ・バックログ・閉じる・ロード・スキップで新規既読を作らない。異なる解像度のページ境界は文字範囲の和集合で照合し、未表示の隙間は補完しない。読んだこと自体を計測するものではなく、表示済みページをプレイヤーが送った記録。

安全な節は個別アダプターの許可リストで指定。派遣の出発導入0・1節、帰還導入1節、設備・支援の導入0・1節だけを許可する。派遣の対象猫・条件を含む後半、店舗イベントの今回の説明、選択、最終確認、全結果、会話終了は毎回手動。派遣帰還の対象猫を示す0節も保持し、次へで送ってから定型の挨拶1節を省略できる。他の共通会話は既読を記録するが許可節はなく、安全側でスキップ不可。追加時は重要情報の位置をレビューして許可する。

一回押すと連続した既読・許可節だけ表示位置を進め、最初の未読／保護節で止まる。自動継続モードはない。同一フレームの連打は既存の入力ガードで一回に制限。選択・確認中・設定中・処理中・バックログ中は動かない。Next/回答/支払い/加入/報酬/営業再開を呼び出さない。今回の許可節は終端を含まないので、最後の「会話を終える」を手動で操作し、既存FinishとExtra登録を一度通す。

## 保存と互換

営業保存ディレクトリの `conversation-read-v1.json` はスロット・Extra・オプションから独立。ページ送りごとにディスク最新記録を読み直して結合し、一時ファイルのflush・読戻し検証・既存の原子的置換と.bakを使用する。ゲーム開始・古いスロットのロードは記録を消さない。書込失敗では営業進行を止めず、保存されなかった範囲は次の起動で未読となる。欠落は空集合。破損／未知版は既読なし・上書き拒否とし、自動バックアップ復旧で不確かな既読を補わない。複数プロセスの同時書込や端末同期は対象外。10万範囲を上限に安全に保存を拒否する。

従来Extraのcompleted/viewed_branches、旧スロットの節番号から詳細既読を推測しない。導入のスキップは許可済みの表示範囲に限られ、新しい未読分岐やCGを解放しない。Extra回想は今回スキップ対象外で、詳細既読も書き込まない。既存の回想終了・ゲーム状態非変更・CG解放規則を維持する。
