# 好感度の節目イベントと会話画面の演出

2026-11-12 時点の設計案。現行の編集手順とデータ仕様は [個別イベントの全猫対応](OptionalEventsAllCats.md) を参照。

## 発生と好感度の上限

- 全猫を対象に、好感度20・40・60・80・100でそれぞれ1話を用意する。本文は画像系統と節目で共有し、発生・進行・完了は猫の個体と節目ごとに記録する。
- 好感度が20・40・60・80に達すると、その猫の好感度は対応するイベントを読み終えるまで、その値を上限とする。1回の交流で節目を超える場合も、その節目で止める。100のイベントは関係の締めくくりとする。
- どちらの選択肢を選んでも、結果の最後まで読むと次の好感度上限が解放される。会話を閉じた時点では完了扱いにしない。
- 上限に達していても、通常営業・おまかせ・他の猫との交流は続けられる。交流前に「好感度20で上限・個別イベントを見ると解放」のように案内し、一覧へ移動できるようにする。
- 本文が未登録の節目は通過できる。猫ごとに順次制作し、登録済みの話から配信できるようにする。

現行の絆目標は好感度80を参照する。新規プレイで20・40・60のイベントが登録済みなら、それらの完了がその猫を絆目標の対象にする条件となる。80に到達した時点で絆目標の判定は行われ、80のイベント完了は好感度をさらに上げるときに必要になる。

## 発生済み個別イベント一覧

- 現行の個別イベント一覧を拡張し、発生済みで未完了の話を猫名・節目・タイトルで表示する。未開始は「未読」、読みかけは「途中から再開」とし、好感度が止まっている猫は一覧から分かるようにする。
- 読みかけの位置を話ごとに保持し、会話を閉じて別の猫の話を開けるようにする。完了した話はExtraから見返せるようにする。
- 既存セーブの好感度を維持する。移行時点で到達済みの節目は、本文があれば一覧に出す。今の値より低い節目へ戻さず、移行後に到達する節目から上限を適用する。
- ミケの「少し近づいた午後」は既存のイベントIDと本文を使って好感度20の話に引き継ぐ。完了済みなら再読を求めず、途中なら開始時の本文と位置を維持する。

## 制作ツールと演出

- 編集画面では画像系統と好感度の節目を選ぶ。現行の本文・話者・選択肢・結果の編集に加え、場面の背景とスチルを指定し、採用前に両分岐をプレビューできるようにする。
- 背景は店内の窓辺など場所ごとに制作して共用する。最初に個別イベント画面の簡易店内描画を背景画像に差し替える。
- 個別イベント画面の猫画像は現行の約322×310の固定枠から拡大し、会話欄の上の表示領域に合わせて縦横比を保つ。猫の名前ラベルは画像と重ならない位置に置く。
- 導入・結果1・結果2にはスチルを任意で指定できる。スチルのある場面は背景と猫画像を一枚絵に切り替え、未指定の場面は背景と猫画像で表示する。会話の開始時に使用する画像の参照を記録し、途中再開とExtraでも同じ画像を使う。

## 最初の試作

ミケの好感度20イベントで、描き込んだ窓辺の背景、拡大した猫画像、分岐後のスチル1枚を試す。好感度20で止まっても通常営業を続けられること、一覧から再開してどちらの分岐でも上限が解放されること、Extraでスチルを見返せることを確認する。会話画面は既存の検証解像度1024×768と1280×800で、本文・選択肢・猫画像が重ならず操作できることを確認する。
