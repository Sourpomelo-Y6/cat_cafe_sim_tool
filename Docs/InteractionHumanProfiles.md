## 条件別メモ

各人物9条件（ねこじゃらし5、なでる3、休憩1）の計18条件へ、生成用の制約メモを設定した。

| 条件 | 方針 |
| --- | --- |
| ねこじゃらし | 遊びへの誘い。追いかけた・跳びついたなど猫の結果を先取りしない |
| なでる | 触れる前にも成立する声かけ。許可や好反応を得たことは断定しない |
| 休憩 | 手を止め、静かに待つ。睡眠や回復の結果を断定しない |
| 動作共通 | 強さ・速度・手の位置を限定せず、専用操作のどれでも成立させる |
| 素直 | 大げさな駆け引きや急な強い動きを追加しない |
| 合わせる | 相手のペースを尊重し、猫の実際の気持ちは決めつけない |
| 激しく | 少し弾む誘い方。追い立てる命令や乱暴な接触、操作と逆の約束を入れない |
| フェイント | 軽い期待感。驚かせた・だましたなどの結果を断定しない |

「絵の状態」の欄には、具体的な画像を観察していないことと、未確認の姿勢・背景・小道具をセリフに追加しないことも明記した。これらは画像の観察記録ではない。画像に合わせた具体的な声かけを作る場合は、生成前にプレビューを確認してこの欄を補足する。

## 保存・利用・確認

現在の人物資料の編集元は画像出力先の `interaction_subjects.json`。台帳がない場合に使う旧設定は `user_data/interaction_llm_settings.json` の `profiles`（`speech/player`、`speech/guest-1`）へ保持し、条件別メモは同じ設定の `scenes` に保持する。ローカル設定はGit管理外のため、共有する制作方針はこの文書へ残した。

接続先・モデル・共通の文章の希望、既存のミケの資料・場面メモは保持した。採用済み本文・下書き・ゲームセーブは変更していない。18条件の入力検証と、両人物の実生成画面への読込を確認した。今回は設定の保存までとし、LLMへの送信・文章の生成や採用は行っていない。確認記録は `Logs/HumanGenerationSettings/result.json`。
