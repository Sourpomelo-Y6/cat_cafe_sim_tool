# 撮影スタジオからの猫紹介ADV

実装日：2026-10-20。[商店街紹介](UnityDispatchIntroductionConversation.md)の保存・回答・会話・Extra経路を拡張した。対象は撮影スタジオ初回紹介の1本。

## 本文と素材

正本は `CafeDispatchIntroductionDialogue.StudioLines`。導入5節→迎える／見送る→結果各4節。候補の表示名は出発時に確定した名前（ルカ＋既存の派遣紹介番号）、個性・特徴・特性は既存候補定義（穏やかな甘えん坊／白猫・短毛／接客好き）を使う。担当者は「撮影スタジオの担当者」とし、固有名・来歴・撮影経験・目や体格など未設定の外見を追加しない。

導入は帰還確認後の営業準備に担当者から相談が届き、猫の既存プロフィールを紹介。ルカがゆっくり近づいてそばに座る仕草を描き、場所と費用を確認して選択へ進む。迎える結果は静かな休養場所を整えて迎え、加入済みの状態を説明。見送る結果は無理なく迎える準備を大切にする返答と、費用・人気・派遣報酬が変わらない説明で終える。全文は上記ソースに固定で収録し、実行時生成はしない。

実候補IDは既存の `dispatch-rescue-N`。表示素材IDは派遣記録の行き先から既存の `intro-cat_photo_studio` に変換される。presentationにはルカがあるが、使用中のCatCafeContentカタログが参照するbundleには当該IDの画像登録がないことを確認。共通の猫シルエットへフォールバックする。商店街や別の白猫の画像を流用しない。新規画像・音声・LLMなし。

## 接続とルール

`Supports`が商店街と撮影スタジオを扱い、同じパネル・進行リストを使用する。派遣先は実際の派遣IDから引き、会話ID・本文・見出しを切り替える。候補・費用・回答可否・飼育枠・残金は既存の投影データを表示し、回答は既存の `RespondDispatchIntroduction` 一回だけ。費用250、資金が費用と同額なら不可、飼育枠、初回限定、解放条件、帰還受取、報酬・加入効果を変更しない。選択付近の残金も投影済み `funds_after` を使う。

共通ADVの文字速度・全文表示・次へ・バックログ・設定・保存読込・閉じるを使用。撮影スタジオ本文とその回想は最大3行のページ送りを有効にする。飼育枠確認から既存画面へ往復できる。満杯・資金不足でも既存の先行イベント制限がなければ見送れる。回答待ち／結果途中はイベント一覧13から再開し、休業の既存理由表示・イベント解消導線を維持する。会話完了後は営業準備へ戻り、自動営業を勝手に開始しない。

## 保存・互換・Extra

新会話IDは `dispatch.photo_studio_introduction.v1`、分岐はintroduction／accepted／declined。商店街の既存ID・本文・セーブ版を保持する。既存 `dispatch_introduction_conversations` の派遣IDごとの進行を利用し、新しい保存フィールドは不要。実回答と分岐を同期し、回答時にページ位置を0へ戻す。表示の再開時に回答を再送しない。既存request_idキャッシュと回答済み拒否、同フレーム入力抑止で支払い・加入を重複させない。

旧セーブで会話メタがない未回答は導入から開始。回答済みは従来の記録表示のまま、未観測の結果会話完了やExtra解放を捏造しない。実派遣先と会話ID・実回答と分岐の一致をロード時に検証する。不正な節のロードは現在状態を保持する。

結果を最後まで読んだ分岐のみExtraへ追加。商店街とは独立した2キーを登録し、実候補の名前とスタジオ本文を保存する。回想は共通の読取専用パネルを使い、選択・支払い・加入コマンドを発行しない。
