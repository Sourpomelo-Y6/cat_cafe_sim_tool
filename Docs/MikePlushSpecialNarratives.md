## 条件・成立・画像

全条件 `mode=plush / reaction=any`。人物欄 `kind=speech / subject_id=player / target_cat=cat-mike`、猫欄 `kind=cat_response / subject_id=cat-mike`。条件キー全文は登録記録を参照。

|場面|action / scene_key|成立と書き分け|選択画像|
|---|---|---|---|
|switch|switch / plush__switch|ぬいぐるみへの切替。前の動作を限定せず、新しいねずみへの注目。|plush：座り姿、前足の先にねずみ|
|connect|connect / plush__connect|心をつかむ操作が確定。誘いを受け止めたことを描き、心を開いたとは断定しない。|plush：基本画像|
|open_up|any / plush|実open_up_count増加。操作共通のため動かし方・接触・抱え込みを限定せず、穏やかな親しみ。|plush__open_up：伏せた姿、穏やかな目|
|simultaneous|connect / plush__connect|connectとopen_up_count増加の同時成立。誘いへの応答と親しげな表情を一つの反応にする。|plush__simultaneous：細めた目、ゆるんだ口元|

`CafeNarratives.Observe`の優先順位は同時成立→心を開く→心をつかむ→切替→通常。switchに心を開く結果が重なればopen_upが選ばれる。心をつかむ操作はテンションの任意／強制条件、心を開く結果はengagement等の成立条件から判定され、本文や登録の有無でルール・数値は変わらない。open_upはdirect/adapt/intense/feint/pause/switchに対応する操作共通文。今回は自然プレイでの各場面到達や頻度を計測していない。

画像はTool実採用PNGをプレビューで解決し、パス・SHA-256・解決キーを記録。Docsの基本・心を開く・同時成立原画も確認した。特別画像にはぬいぐるみへの接触が描かれていても、本文では捕獲や抱え込み成功を断定しない。口の開きを鳴き声として扱わない。画像・対応は変更しない。
