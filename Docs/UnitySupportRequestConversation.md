# 支援依頼の共通ADV接続

実装日：2026-10-22。店舗イベントの `support` 1種類を、設備トラブルで追加済みの共通3択・日別案件・進行停止・保存・Extraへ接続した。発生確率、支援費、人気加点、上限、回答可否、閉店処理は変更していない。新規画像・音声・実行時LLMは追加していない。

## 本文

導入：「保護団体から、活動への支援をお願いする連絡が届いた。」→「店の資金を確認して、支援するか、少額を支援するか、今回は見送るかを決めましょう。」→保存した選択肢の説明と、未回答では営業・休業ができないこと、閉じた場合の一覧再開手順。

3択は「支援／少額支援／見送り」。結果は「{発生日}日目の支援依頼は『{回答}』で回答しました。」→確定した支出と残金、人気反映の時点または経営終了→「回答は記録済みです。店の状態を確認して、これからの予定を決めましょう。」。見送りの最後は「今回は見送りとして記録しました。店の状態を確認して、これからの予定を決めましょう。」。団体名・事故・個別の救助対象・原因・担当者は追加していない。

## 数値と操作

費用と人気加点・上限は、現在ロードしている `Simulation.Rules.store_events` と `Rules.popularity.cap` から表示する。資金は現在状態から取得し、選択肢と最終確認には支出前→支出後を表示する。通常設定の100／50、人気5／2、上限650を会話本文の固定仕様にしない。導入で読んだ説明は案件へ保存し、選択時と最終確認では現在の選択肢を取得する。

既存 `CafeSimulation.ResolveStoreEvent` だけが回答と即時支出を確定する。人気は既存 `Close` の人気計算で閉店時に加算し、他の人気変化と上限を適用する。会話・読込・Extraはこれらを再実行しない。支援後に休業した場合も既存の閉店処理で反映する。

既存ルールは支援額以上の残金を必須としていない。資金が0以下になる選択も許し、最終確定前に残金と経営終了、閉店時の予定加点が未反映で終わることを表示する。新しい禁止条件は追加していない。見送りは支出0・人気追加なし。

3択は共通 `EquipmentConversationPanel` を店舗選択型として共用する。`AcquisitionConversationPanel` に共通の最終確認を追加し、取消ではコマンドを送らない。長い説明は既存スクロール、本文は最大3行ページ送り・文字速度・全文表示・次へ・バックログ・保存読込・オプションを共用。背景とシルエットは既存表示。設備トラブルの休業プレビュー・確認は従来のまま。

## 進行・表示順

回答前は既存の店舗回答待ちで営業・休業を止める。導入3節目と休業不可理由に、イベント一覧の「店舗イベント」から再開して回答する手順を示す。閉じても未回答・位置を保持する。

回答後は結果読了まで共通の店舗結果待ちとして営業・休業・成長回答・目標継続・他の状態変更を止める。保存・読込・新規開始、おまかせの停止と一時停止は可能。画面を閉じた場合はイベント一覧に未完了表示を出し、共通の具体的な停止理由から同じ案件を再開する。支援結果→残る帰還・他の会話→成長→目標結果・経営終了、という設備の共通制御を利用する。即時の資金終了でも支援結果を先に表示し、読了後に既存の資金不足の結末へ戻す。支援の結果を読み終えた後の閉店では、成長や目標結果を妨げない。

## 保存・互換・Extra

支援の会話IDは `store.support.v1`、案件IDは `support-request-{発生日}`。日別の本文、回答結果、節・ページ位置、読了分岐を保持する。別日に同種が発生しても混ぜない。既存の設備セーブを維持するため、共通化後も保存フィールド `equipment_conversations` と `equipment_conversation_selected`、レコード型名は維持する。会話IDで種別を区別し、保存検証では実際のイベント種別・日付・回答に照合する。既存 `repair_effect`／`patch_effect` フィールドは共通3択の第1／第2説明として再利用する。

案件ID、instance/revision、操作IDの既存検証を利用し、別案件の回答・同一要求の再送・連打を重複精算しない。旧窓口の空案件IDは既存revision検証の下で互換維持。未読結果がある間も再回答を拒否する。読込で再抽選・再回答・人気反映を行わない。

旧未回答は未読導入を作る。旧回答済みで会話記録のない過去案件は結果を捏造せず、既読にせず、進行を強制停止しない。旧設備会話の位置とExtraは維持する。初期ゲーム設定の識別子は今回変更していない。

結果の「会話を終える」まで閲覧した支援／少額支援／見送りだけをExtra登録する。同一分岐は代表記録1件にまとめ、当時保存した導入・結果を再生する。回想では本編の資金・人気・日程・回答・会話位置を変更しない。未記録の旧会話は解放しない。
