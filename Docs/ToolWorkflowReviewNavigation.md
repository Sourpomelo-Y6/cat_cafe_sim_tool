# 不足条件の編集・画像ID資料編集・採用前全文比較

2026-10-28。第2・3段階に残した3項目を実装。

## 操作

- 画像付きプレビューの「未制作の条件」で一覧から条件を選び、「この条件を編集…」。対象・動作・操作・反応・通常／特別場面・適用猫を保ったまま既存の編集画面へ移る。主画面の確認タブからも文章編集中からも使用できる。
- 人物の不足条件はプレビューで選んだ猫への専用文として開く。共通文を作る場合は編集画面の適用範囲で明示的に変更する。特別文の不足は通常文と区別し、未制作をすべて制作必須とは扱わない。
- 編集中の文章があれば既存の下書き保存／破棄／キャンセル確認を使う。キャンセルでは本文も条件も保持する。採用後はプレビューで「登録済み素材を再読込」する。
- 対象台帳を使う通常Toolのプレビューでは画像IDを読み取り専用にした。「資料で画像IDを編集…」から対象猫の資料画面へ移る。保存には従来の台帳競合検出を使い、保存後にプレビューを更新する。開く・閲覧するだけでは対応を変えない。資料の未保存変更はプレビュー／親画面終了時にも確認する。
- 台帳なしの旧単独プレビューだけは、従来の画像対応ファイルへの保存操作を互換経路として維持する。通常Toolは台帳を渡すため新しい資料編集導線を使用する。
- 交流文の「登録内容を確認」で案1〜3それぞれの採用済み全文と今回採用する全文、追加／変更／削除／変更なしを表示。適用猫、対象条件、空欄にした候補を外すことも表示する。
- 紹介文と4場面も同様に全文比較する。空欄は定型文へ戻る旨を表示する。比較後の本文変更・別操作による採用文の更新は登録を止めて再確認を案内する。紹介文の下書き自動同期は追加していない。
