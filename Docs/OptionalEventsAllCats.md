# 個別イベントの全猫対応（F1/F2）

今後の節目イベントと会話画面の演出は [好感度の節目イベントと会話画面の演出](OptionalEventAffinityMilestones.md) を参照。

画像系統と好感度の節目ごとに本文を共有し、開始・進行・完了は猫の個体とイベントごとに保存する。[当初の実装・互換・検証範囲](../../Docs/OptionalEventsAllCatsImplementation20261103.md)。先行パックにはミケ20・40、タマ20、ソラ20の4話を収録している。[先行パック](../defaults/priority_optional_events/optional_events.json)

## 編集・採用

1. 素材制作画面の「文章」→「猫の個別イベント…」を開き、画像対象と節目を選ぶ。同名はIDで区別する。「従来の開始条件」では任意の開始好感度を設定できる。
2. 新しい対象は空欄から作る。初期値は導入3行、選択肢2つ、各結果2行。導入・結果1・結果2のタブで行を選び、追加・削除・上下移動ができる。各パートは1〜20行で、追加した行は選択行の直後に入る。話者を空欄にすると地の文になる。数値報酬・名前変数はない。共有する本文へ特定の個体名を埋め込む場合は意図を確認する。
3. 最小日数1～9999を編集する。節目を選んだ場合の最小好感度はその節目に固定する。到達した未完了の話がある猫はそこで好感度が止まり、読了すると次の登録済みの節目まで進める。100は締めくくりの話。在店・健康・営業準備・必須対応優先等は固定。
4. 「下書き保存」は当該系統の下書きだけを保存。「プレビュー・採用比較」で両分岐を確認し、「この内容を採用登録」で採用する。通常の採用は当該系統だけで、下書きを勝手に更新・移行しない。
5. 出力対象チェックを外して採用すると、その系統の新規開始だけを止める。本文とゲームの進行記録は残る。
6. 「イベントだけ出力…」または通常の素材一括出力で、有効な採用定義をすべて出力する。選択中の猫だけの部分更新ではない。
7. Unityの既存素材取り込み入口で全体置換の案内を確認して取り込む。通常Playerへは再ビルドで反映する。

「背景」で共用背景を選び、導入・結果1・結果2の各タブでスチルを指定できる。スチルの場面では一枚絵を表示し、選択肢の場面とスチル未指定の場面では背景と猫画像を表示する。「プレビュー・採用比較」の両分岐で指定と画像を確認できる。

選択肢には同梱済みの窓辺背景とミケのスチルがある。イベントパックには画像の版付きIDを含める。演出を変更して採用すると定義の版が変わり、新規開始に反映される。途中再開とExtraは開始時に記録した指定を使う。画像指定付きパックの取り込みには対応版のUnityが必要。

旧ミケは個体専用のまま読む。「この系統で共有する（旧ミケのみ）」を明示的に選び、本文中の猫名・比較内容を確認して採用した場合だけ、同じ画像系統の別個体も開始できる。イベントIDを保ち、元のミケの完了を取り消さない。

## 出力済み定義の再編集

「出力済み定義を下書きへ…」は下書き全体の読込。非空パックはその定義一覧で置換し、空パックは既存本文を保持して全件出力除外の案を作る。採用はまだ変わらない。

先行4話を制作ツールで編集するときは、同じ操作で先行パックを読み込む。

読込後の「プレビュー・採用比較」は全下書きと全採用の比較となり、その後の採用ボタンで全体を確定する。個別編集と異なる全体操作であることを案内と比較画面で確認する。比較後に編集・対象変更した場合は比較をやり直す。

## 互換と上限

- 新規出力は `optional_events.json` version 2。最大64画像系統に、従来の開始条件1件と20・40・60・80・100の各1件を登録できる。JSONは1,000,000 UTF16単位まで。通常bundle版は変えない。
- 行数を変えた定義の取り込みには可変行数対応版のUnityが必要。従来と同じ行構成の定義は既存の版IDを維持し、行を別のパートへ移した場合は版IDが変わる。開始済み会話は開始時の行構成で続く。
- 下書きと採用は別ファイルの保存版2。旧v1は開く／出力だけで変更せず、初回編集時にそれぞれ `.v1.json` へ原本を退避する。退避不一致・破損時は上書きしない。
- 節目の会話は複数を読みかけにできる。閉じれば通常操作を続けられ、一覧から猫と節目を選んで再開できる。従来の開始条件で作った話は同時に1件まで進行できる。
- ゲーム保存は512履歴／任意イベント欄16,000,000 UTF16単位まで。画像・定義の削除、病気・不在・譲渡後も、開始時の本文と位置を保持する。上限でも既存の再開・完了・通常保存は可能。
- Extraはイベント・本文版・選んだ分岐ごとに共有。別個体の同じ版・分岐で、先に記録した猫名・本文・画像を上書きしない。各個体の完了は独立。
- 定義なしの旧パックはイベント参照を保つ。明示空定義は新規開始を無効にする。開始済み・完了済みは消さない。
- 保証する互換方向は旧→新。新しい複数個体の保存・Extraを旧F1/F2アプリで読めるとは保証しない。

[旧F1の記録](OptionalEvents.md)／[旧F2の記録](EventAuthoring.md)。先行4話以降の本文制作、報酬・一般条件式・個体別の回想棚は別範囲。
