# タイトルのExtra：閲覧済み会話の回想

実装・検証日：2026-10-18。[商店街からの猫紹介](UnityDispatchIntroductionConversation.md)までの閲覧完了記録を、営業スロットをまたぐ共通の回想記録へ接続した。タイトルの「Extra · 会話の回想」から開く。

## 対象と操作

| 会話 | 解放対象の分岐 |
| --- | --- |
| 保護猫の受け入れ依頼 | 迎える／見送る |
| 常連からの猫紹介 | 迎える／見送る |
| 近所のお店への訪問 | 出発する／今回は出発しない／派遣中／帰還 |
| 商店街の追加のお願い | 引き受ける／予定どおり終える |
| 商店街からの猫紹介 | 迎える／見送る |

合計12分岐をスクロールできる一覧へ表示する。閲覧済み／未解放を明示し、未解放はボタンと直接の呼び出しの両方で開けない。結果の分岐を選ぶと導入からその結果まで続けて再生する。派遣中の閲覧は単独。回想内で迎えるなどを選び直す操作はない。

ReplayConversationPanelはAcquisitionConversationPanelを再利用し、全画面の「やさしいADV」、話者・地の文・猫画像、全文表示／次へ、スクロール、バックログを使う。保存／読込／選択肢を非表示にし、回想終了と途中で閉じる操作はExtra一覧へ戻る。タイトルへ戻って「はじめから／つづきから」へ移れる。共通ADVに入力可否・画像・進行停止・完了処理などの小さな差し替え口を追加した。

回想の入力、終了、表示更新はゲームへのコマンドを発行しない。ゲームの資金・所属・日付・revision・会話進行・営業セーブ・閲覧解放集合を変更しない。ゲーム状態は持たず、表示用の節位置だけを使う。会話の初期画像を既存の素材カタログから取得し、不足時は既存の猫シルエットへ戻す。新規画像・音声・実行時LLMはない。

## 共通記録と既存セーブの取り込み

既存の会話ID＋分岐IDをキーに、通常の営業セーブディレクトリstandalone-v1へ別ファイルextra-v1.jsonを保存する。10個のslot-N.jsonとは独立し、同じディレクトリを使う全目標・全スロットで共有する。新規開始や古いスロットのロードで解放記録を減らさない。別のディレクトリで運用した記録、別端末、クラウド同期をまとめる仕組みは今回対象外。

通常プレイの「会話を終える」で各シナリオのcompleted／viewed_branchesが確定した直後に共通記録へ反映する。営業の保存時とロード前にも既存の完了記録を結合する。同じキーは一つだけで、最初に記録した名前・個性・会話本文のスナップショットを保持する。後日の別の猫や別の紹介者で同じ会話を見ても、今回のExtraには代表の一件を表示する。営業セーブ内の個々の派遣・候補記録は従来どおり残る。本文のバージョンを変える公開後の更新では会話IDの版と移行を用意する。

記録は会話ID・分岐ID・見出し・画像用猫ID・猫名・個性・話者付き本文のみ。ゲーム状態、費用コマンド、加入処理、日付を保存しない。閲覧記録のFromSaveは既存の会話・分岐・節・実回答の検証を通してからviewed_branchesだけを抽出する。回答だけ確定していても、結果会話を最後まで読んでいなければ解放しない。導入は解放分岐として扱わない。出発しない結果を読んだ後の再相談でも、既存の閲覧完了集合に残る分岐を取り込める。

Extraを開くと現在のゲームとslot-1からslot-10、およびそれぞれの.bakを読み取り専用で確認する。保存の版・スロット番号・日時、現行ルールに対するゲーム状態、会話メタデータを別の検証用シミュレーションで確認し、稼働中のゲームへはRestoreしない。既存セーブを再保存しない。閲覧完了メタデータがない旧セーブに未観測の解放を作らない。互換性がないルールIDや不正な保存はスキップし、その件数を一覧に表示する。未対応のPythonセーブを直接解放に使う変更ではない。

共通記録は書込前にディスクの最新記録を再読込して結合する。古いバックエンドインスタンスによる逐次書込みでも解放を落とさない。現在の形式・既知キー・重複・本文サイズなどを検証し、一時ファイルのフラッシュと読戻し検証の後、既存CafeSaveStore.ReplaceWithRetryによる原子的置換と.bakを使う。主記録が読めなければ検証済みバックアップを使用し、修復時は壊れた主記録を.invalidへ退避して良い.bakを残す。両方とも読めない場合は上書きせず一覧へ読み込みエラーを表示する。書込み失敗時は以前の記録を維持し、Extraを開き直して再試行できる。営業スロットには影響しない。複数のPlayerが同じディレクトリへ同時に書く運用の排他制御は今回対象外。

実装はCafeReplayCatalog（既知12分岐と閲覧記録の抽出）、CafeReplayStore（独立ファイル）、LocalCafeReplayArchive（ゲーム窓口と旧記録の検証）、TitleExtraPanel（一覧）、ReplayConversationPanel（副作用のないADV）に分けた。会話本文とゲームルールは従来の各シナリオ・シミュレーションを維持する。営業セーブの版・ゲームルールID・バランスを変更していない。
