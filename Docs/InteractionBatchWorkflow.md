# 連続生成のスキップ・まとめ保存・汎用初期値

2026-10-16。失敗した項目で連続生成が止まり続けること、1条件ずつ保存・登録する負担、人物セリフの適用範囲がミケ専用で始まる問題を修正。

## 操作

- 「失敗した項目を飛ばして続行」は初期状態でON。不正な回答・通信エラーなどで失敗した条件は「失敗・スキップ」にして、次の条件へ進む。失敗項目を選ぶと理由を表示する。OFFにすると従来どおりその条件で停止する。
- 停止中は、未完了の条件を選び「選択項目を飛ばす／保存対象外」で飛ばして残りを続行できる。失敗した条件を再試行する場合は「選択項目を対象へ戻す」→「未完了の条件を再開」。実行中の通信は従来どおり「停止」で停止を要求し、応答待ち終了後に操作する。
- 完了済みの結果も「選択項目を飛ばす／保存対象外」でまとめ保存から外せる。生成結果は消さず、「対象へ戻す」で復帰できる。
- 「完了分をまとめて下書き保存」で、保存対象の全条件を一度に下書き保存する。1件ずつ編集欄へ取り込む必要はない。
- 「完了分をまとめて確認・登録…」を開くと、対象条件と各3案を一覧で読める。「確認した○条件をまとめて登録」で下書きと登録済み素材へ反映する。失敗・スキップ・保存対象外は含めない。生成しただけでは自動登録しない。
- 個別修正が必要な結果は従来の「選択結果の3案を編集欄へ」を使う。生成開始後に変更した文章や、編集欄にある未保存の文章をまとめ操作で上書きしない。既に同じ内容を保存した結果の再保存は可能。
- 完了結果・失敗理由・スキップ・保存対象外・保存時のスナップショットは「前回の続き」に保持する。追加情報のない旧記録も読み込める。

人物セリフの編集画面は「どの猫でも使う（{cat_call}）」で開く。猫の反応から人物セリフへ切り替えた場合も汎用が初期値。従来のミケ専用素材を明示的に開いた場合は専用範囲を維持し、既存本文・条件・候補IDを移行・変更しない。

汎用条件に個別の生成メモがなければ、同じ動作・操作の旧メモを参照し、生成入力でのミケ固定の記述を対象の猫へ置き換える。保存済みメモ自体は変更しない。画像付きプレビューの「編集中の案を重ねる」では編集中の汎用案を確認できる。実際のゲームでは従来どおり猫専用文が優先されるため、画面にもその違いを表示する。

## 保存の検証と制限

まとめ保存は全条件の形式・候補・競合を検証した後、文章ファイルを一度だけ置き換える。競合や不正な候補が1件でもある場合は、そのファイルを一部だけ更新しない。他の条件は保持する。

下書きと登録済み素材は別ファイルで、両ファイル間の一括トランザクションではない。確認登録では両方を事前検証し、下書き→登録済みの順に保存する。後者の書き込みだけが失敗した場合、登録済み素材は旧内容を保持し、保存できた下書きは残る。エラーを解消して同じ結果から再試行できる。
