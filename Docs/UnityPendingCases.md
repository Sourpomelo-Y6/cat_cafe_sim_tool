# 複数案件の残件一覧と営業再開（2026-10-24）

## 変更範囲

既存イベント一覧の4分類・スクロール、共通ADV、既存の営業／自動進行／おまかせ操作を再利用した。回答・確認待ちと、回答済み・結果会話未完了を案件ごとに表示し、合計と内訳を表示する。従来の「結果が一つでもあれば、その種類全体を1件」とする集計を置き換えた。

対象は受け入れ、店舗選択、成長、家出帰還、譲渡、常連紹介、特別予約、信頼、通常／有力者派遣帰還、派遣途中選択、宿トラブル、派遣先紹介。派遣中の任意説明、来訪猫の任意交流、信頼回復中や家出／宿の帰還日程待ちは追加しない。通知は従来の別分類から閲覧できる。

案件にはイベント名、猫・人物、発生／派遣日、行き先、案件ID、続きへの操作、先に必要な確認を表示する。派遣は派遣IDと行き先、家出は案件ID、成長は猫と成長項目で識別する。信頼・店舗・派遣などの準備処理が、明示選択した別案件を先頭の未読案件で上書きする挙動も修正した。

会話の「閉じる」と読了後は一覧へ戻る。次のイベント会話は選んで開く。表示位置・読了履歴は既存の保存方式を利用し、回答・費用・報酬処理を呼び直さない。表示用ボタンもクリック時に現状態の案件を再照合する。

一覧を開くと通常の自動進行を停止する。閲覧や読了だけで営業を再開しない。下部に、既存の実行可否判定に応じた「営業開始」「自動進行を再開」「翌日へ」「おまかせを再開」を表示する。おまかせは実行中・一時停止・中止済み・終了を通常自動進行と区別する。中止済みの実行を再開せず、その段階の通常操作へ戻す。未解消の優先案件や出勤等の条件があるときは再開ボタンを無効にする。新規・ロードによるinstance切替と既存ResetNavigationで、一覧の戻り先と手動選択の保持を消す。

既読短縮・スキップ、会話本文、Extra解放条件、ルールJSON、バランス値は変更していない。

## 検証の再現

```powershell
dotnet cat_cafe_sim_tool/tests/standalone/bin/Debug/net8.0/StandaloneChecks.dll --conversation cat_cafe_sim_tool/unity_preview_template/Resources/CatCafeStandalone/rules.json
cat_cafe_sim_tool/build_standalone.ps1 -ProjectPath C:/Users/hi-wa/unity_workspase/CatCafeSim -ExecuteMethod CatCafePreview.Editor.PendingCasesVerification.VerifyAndBuild
```

`StandalonePendingCasesSmoke`は明示した`--catcafe-pending-check <専用絶対パス>`だけで起動する。専用ルールで自然進行させ、同日の複数信頼警告のうち1件へ回答し、結果会話の途中をslot-9へ保存する。`--pending-resume`は別プロセスからその保存を読む。`--pending-last`は他の案件を検証用に処理済みとして最後の結果1件を用意する。最後の1件の実入力確認用の状態準備であり、全案件を実入力で読んだとの主張には使わない。ユーザーの保存・Extra・設定を検証先に使わない。

Playerの追加検証はUIの通常ボタンのコールバックを呼ぶ検証と、検証用状態準備を含む。Windowsの実入力は下記で分ける。多数行だけは投影へ8件の成長表示を加え、既存スクロール領域の高さと最下部への移動を検証する。これは8件の自然な成長発生を再現した試験ではない。

## 後続課題・限界

全イベント順列、全猫・人物、全解像度の総当たりではない。既存個別回帰で保存互換・連打・費用報酬の重複拒否を確認し、新しい一覧と再開導線は複数信頼案件を中心に配布Playerで確認する。全目標の長期評価と総合通しは繰り返していない。

会話頻度と反復負担、既読短縮／スキップの操作方式は後続設計とする。今回の一覧改善を理由に本文やExtraの解放単位を変えない。既存の未コミット画像・物語・表示設定は今回のコミットへ含めない。Unity側の先行差分も維持する。
