# 素材パック間の同一PNG

| 指標 | 集計 |
|---|---:|
| 調査対象パック | 50 |
| PNGファイル数 | 5,405 |
| PNGのファイルサイズ合計 | 10.65 GB |
| バイト列が異なる画像の種類 | 899 |
| 複数パックにある画像の種類 | 890 |
| パック間の重複分 | 8.79 GB（PNG合計の約82.6%） |
| 同一内容を1組ずつ数えた場合 | 1.86 GB |

## 現行パックと旧セーブが参照するパック

| パック | PNGファイル数 | 同一画像 |
|---|---:|---:|
| 現行 `ad3e7e84e8c7491fb8aad895e243de4e` | 860 | 860 |
| 旧 `cbe0df94e7a5401a8f466406c105b493` | 860 | 860 |

両パックで、PNG 860枚、1.80 GB の内容が一致しました。確認済みの旧セーブ2件が旧パックのリソースパスを保持しています。

## 集計方法

- Unity プロジェクト内の通常素材、人物画像、任意イベント、状態画像、見た目画像のパックフォルダを対象とし、各PNGの実データをSHA-256で照合しました。パック外の共通素材やメタファイルは対象外です。
- 重複分は、同一のPNGを1ファイル分だけ残すと仮定したファイルサイズ差です。今回、重複グループ内の既存ハードリンクは確認されませんでした。
- 容量はプロジェクト上のPNGのファイルサイズです。Unityが生成する圧縮済みWindowsビルドの削減量は別に計測する必要があります。
- 参照元の分類には先行の素材パック一覧で調べた旧セーブを使いました。パックとセーブは読み取り専用で扱いました。
