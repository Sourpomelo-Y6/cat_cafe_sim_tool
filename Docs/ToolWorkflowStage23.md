# 制作Tool：人物画像と確認・書き出し

2026-10-28実装。第1段階に続く第2・3段階の主な導線を接続。

## 操作

- 主画面は「対象管理／文章／画像／確認・書き出し」の4タブ。生成設定は検索欄右の別窓。人物選択中は猫生成設定を無効化する。
- 人物を選び「画像」へ。採用済みと候補を左右に比較し、PNG選択→「この人物画像を採用」。選択だけでは台帳を変更しない。候補は同じ起動中の対象往復でも保持する（再起動後の復元はしない）。
- 有効な客IDを持つ保存済み人物のみ画像を採用できる。プレイヤー・制作専用対象は理由を表示する。人物の場面差分は増やさない。
- 「画像対応を解除」は確認後に既存の解除処理を呼ぶ。PNGは保持する。資料画面にあった既存の人物画像操作は互換導線として残す。
- 「確認・書き出し」で登録概要を更新。採用交流文の条件数、書き出し可能な人物画像数、制作専用・利用対象外、人物画像の警告を表示する。これは全条件の完了判定ではない。
- 「選択対象の文章・画像を確認」で既存プレビューへ。採用済み表示から開始し、組合せと不足一覧を確認する。本文編集は文章タブ、ID対応は既存の対象管理を利用する。
- 主操作「全素材をUnity向けに書き出す」は既存export_bundleを使用。猫画像・紹介文・交流文・人物画像を含み、下書き・未採用候補は含まない。
- 補助操作「人物画像だけを書き出す」は既存CatCafePeople形式を維持。0件のパックは取り込み時に人物画像対応を解除するため、書き出す前に明示確認する。
- 出力後はUnityの通常の素材パック取り込みへ。書き出し成功をUnity収録済みとは表示しない。

## 調査記録の訂正

先行提案では人物画像を別途出力する必要があるように整理したが、現行unity_export.pyは既にhuman_portraits.jsonとpeople画像を全素材パックへ同梱していた。今回は出力形式を追加・変更せず、その実装に合わせて主操作と案内を整理した。
