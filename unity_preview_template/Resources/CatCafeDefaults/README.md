# 猫画像未登録時の共通素材

`cat-silhouette-v1.png` は透明背景の座り猫シルエットです。組み込み画像生成ツールで作成しました。

生成指示：猫カフェゲームの画像未登録用、正方形、全身の座り猫、尖った耳と巻いた尾、落ち着いたチャコールグレー、顔・文字・小物・影なし、透明背景、周囲に余白。

ContentPreviewは登録画像がない、猫の素材対応がない、画像を読み込めない場合に `CatCafeDefaults/cat-silhouette-v1` を読み込みます。猫カード・接客・交流と素材プレビューで共用します。画像未登録の案内は維持します。

受け入れ依頼のPythonIntakePanelと店先の猫のPythonVisitingCatPanelに画像枠を追加しました。候補IDで登録済みの通常画像を取得し、未登録時はシルエットを表示します。出会いのゲーム仕様はゲーム側Docs/HumanToCatVisitingCat.mdにあります。

確認：素材を制作テンプレートとUnityプロジェクトに配置し、コピーのSHA256一致を確認。Unityのバッチ検証で受け入れ・店先の猫の画面を生成し、シルエット表示を検証、スクリーンショットを目視確認しました。PlayモードのHTTP通し確認は未実施です。
