# 本番素材の文章と任意イベント

このフォルダは Unity の本番パック `ad3e7e84e8c7491fb8aad895e243de4e` を再現するための採用済み登録データです。猫の紹介文と場面情報は `texts.json`、任意イベント15件は `optional_events.json` に入っています。

別環境で再書き出しする場合は、制作ツールで使う素材フォルダ（既定は `cat_cafe_sim/saves/content_images`）へ同名で配置します。既存のファイルがある環境では差分を確認し、必要な行を統合してから使います。通常の書き出しには、対応する画像・交流文・人物の登録データも必要です。
